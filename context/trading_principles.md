# Trading Principles

- Separate hard resolution mechanics from market narrative.
- Do not use market orders.
- Prefer sell ladders when price approaches dispute-tax territory.
- Treat social-media rumours as noisy catalyst signals, not facts.
- Track correlation across Iran, Hormuz, oil, and Trump-announcement markets.
- Flag stale context explicitly before increasing exposure.
- Every model recommendation requires human review before any action.
